🌾 कृषि विभागाच्या योजना - महाराष्ट्र शासन
(Maharashtra Agriculture Department Schemes - Digital Guidance Platform)

हा एक ओपन-सोर्स फ्रंटएंड प्रोजेक्ट आहे, ज्याचा उद्देश महाराष्ट्र शासनाच्या कृषी विभागामार्फत राबविल्या जाणाऱ्या विविध योजना, मार्गदर्शक सूचना, शासन निर्णय (GR), आणि अर्ज नमुने (प्रपत्रे) एकाच डिजिटल व्यासपीठावर उपलब्ध करून देणे हा आहे.
